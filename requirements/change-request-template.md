# Change Request

| Field | Value |
|---|---|
| **CR ID** | CR-001 |
| **Artifact** | e.g. PSVS-REQ-v1.0 / S7 |
| **Reason** | Why is the change needed? (defect ID, e.g. D15) |
| **Impact** | Affected requirements, models, proofs, tests, effort, risk |
| **Approver** | Name / role |
| **Date** | YYYY-MM-DD |
| **Status** | Proposed / Approved / Rejected / Implemented |
